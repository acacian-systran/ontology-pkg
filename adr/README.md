# 결정 기록 (ADR)

책 [2.3]. 여기 없는 결정은 3주차에 반드시 되돌아온다.

한 결정에 파일 하나. 번호는 안 재사용한다. 뒤집을 때는 지우지 않고
새 ADR 을 쓰고 이전 것의 **상태**를 `대체됨 — 000N` 으로 바꾼다.

`template.md` 는 일반적인 최소 형식이다. 책 [2.3] 이 다른 형식을 쓰면 그쪽에 맞춘다
(`./book 'ADR'` 로 확인).
