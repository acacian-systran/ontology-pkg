# 0003. 버전 표현 방식

- **상태** — 검토 중
- **날짜** —
- **관련 절** — [2.2], [11.2]

## 맥락

버전을 독립 개체(`PackageVersion`)로 둘지, 패키지의 데이터프로퍼티 리터럴로 둘지.

개체로 두면 버전마다 의존·라이선스·취약점을 따로 붙일 수 있고 11장 시간 모델이 자연스럽다.
리터럴로 두면 그래프가 작지만 "이 버전이 무엇에 의존하는가" 를 표현할 자리가 없다.

함께 정할 것 — semver 를 문자열로 둘지 major·minor·patch 로 쪼갤지.
[5.4] 집계와 [5.3] FILTER 에서 정렬·비교가 필요해지는 지점이 여기다.
